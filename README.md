Train Reservation & Management System
Train Reservation System – Software Engineering Project
A web-based Train Reservation & Management System designed to manage passenger registration, train ticket bookings, user accounts, and reservation information.
Built using HTML, CSS, and JavaScript, with LocalStorage for storing data. The project runs entirely on the client side without requiring a backend server.
Overview
The system provides a simple interface for managing train reservations and passenger information.
Main features include:
* Passenger registration and login
* Train ticket booking
* Passenger profile management
* Viewing and managing reservations
* Ticket cancellation
* Reservation history
* Reports and dashboard pages

How to Run the Project
Option 1: GitHub Pages
Open the live website:
https://alotaibinorah.github.io/Train-Reservation-System/
Option 2: Run Locally
1. Download the repository as a ZIP file.
2. Extract the project folder.
3. Open index.html in your browser.
4. Navigate through the system using the available pages.
