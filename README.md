
Train Reservation System

Project Overview
The Train Reservation System is a web-based application designed to simplify train reservations and passenger management.

The system allows users to explore train routes, select seats, book tickets, and manage their reservations.

Main Features
* User Registration and Login
* Train Route Management
* Seat Selection and Booking
* Booking Confirmation
* Ticket Cancellation
* Passenger Profile Management
* Booking History
* Reports and Statistics

Technologies Used
* HTML
* CSS
* JavaScript
* LocalStorage
  
How to Run the Project
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your web browser.
4. Start exploring the system.
